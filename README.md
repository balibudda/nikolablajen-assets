# nikolablajen-assets

Public, low-sensitivity file host for nikolablajen.com — the apk download and temporary social-media video files that need a plain public URL for cross-posting (Instagram/Facebook/Threads all fetch a file by URL, they don't accept direct uploads). Moved here 2026-09-08 after Vercel Blob's team-wide free 'Advanced Operations' quota (2000/month) got exhausted and locked all 3 of nikolablajen-app's Blob stores until the next billing cycle — see nikolablajen_app/CLAUDE.md for the incident writeup.

Nothing here is app source code or a secret. Assets are attached to GitHub Releases, not committed to git history (keeps clone size small).
